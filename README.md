# KiCad App live acceptance fixture

Dedicated public test repository for the owner-only KiCad Review Live Test App. These are original synthetic demonstration designs from wayri/KiCad-Online examples/sensor. They are not electrically validated or fabrication-ready.

Tests cover OAuth, selected repository installation, saved PR reviews, failure/retry and uninstall. Native ERC/DRC is deferred. No CI scripts or private designs are used.
